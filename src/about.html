About

This site is a small, static collection of quotes. There's no database and no server — everything you see is generated ahead of time from a single CSV file and served as plain HTML, CSS, and JSON.

How it works

Quotes live in data/quotes.csv, with a column each for the quote text, author, comma-separated tags, and source. A small Node.js script (scripts/generate.js) reads that file and produces:

  • quotes.json — every quote as structured data
  • meta.json — tags, sources, and authors, each with counts

The browse page loads quotes.json in the browser and filters it entirely client-side — no page reloads, no backend calls.

How it's updated

A GitHub Actions workflow runs the generator script on every push to main, commits the regenerated output, and deploys it to GitHub Pages. Add a row to the CSV, push, and the live site updates itself within a couple of minutes.

More

Curious about a specific quote's context, or think one's misattributed? The Sources page lists everything cited in the collection, and each quote card on the Browse page shows its source directly when one is on file. For anything else, the project's source is on GitHub — open an issue or a pull request with a correction or addition to the CSV.
